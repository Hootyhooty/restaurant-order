# Picha Restaurant

Online restaurant platform for browsing the menu, ordering souvenirs, booking a table, and managing your account.

**Live site:** [https://picha-restaurant.com/](https://picha-restaurant.com/)

## What you can do

- Browse meals and leave reviews
- Shop souvenirs and pay online
- Reserve a table, with optional pre-order
- Create an account, verify email, and manage your profile
- View current promotions
- Contact the restaurant

## Built with

React, Node.js / Express, MongoDB, and Stripe.
